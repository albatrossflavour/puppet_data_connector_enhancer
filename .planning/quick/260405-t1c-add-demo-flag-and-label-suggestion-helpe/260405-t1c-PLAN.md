for which fields to use as Prometheus labels versus value fields.

**3. `suggest_labels_from_data(data)` private method:**

Takes the Array of Hashes from PuppetDB. Uses the first row to walk the structure.

Walk the first row's hash recursively, building dot-paths for leaf values:

```ruby
def suggest_labels_from_data(data)
  return if data.nil? || data.empty?

  row = data.first
  string_fields = []
  numeric_fields = []
  skipped_fields = []

  walk_structure(row, '', string_fields, numeric_fields, skipped_fields)

  puts ''
  puts '--- Field Suggestions ---'

  if string_fields.any?
    puts ''
    puts 'Potential LABELS (string fields):'
    string_fields.each { |path| puts '  --labels %s=%s' % [label_name_from_path(path), path] }
  end

  if numeric_fields.any?
    puts ''
    puts 'Potential VALUE fields (numeric):'
    numeric_fields.each { |path| puts '  --value-path %s' % path }
  end

  if skipped_fields.any?
    puts ''
    puts 'Skipped (timestamps/complex):'
    skipped_fields.each { |path, reason| puts '  %s (%s)' % [path, reason] }
  end

  puts '-------------------------'
  puts ''
end
```

**4. `walk_structure(obj, prefix, strings, numerics, skipped, depth = 0)` private method:**

Recursive walker with max depth of 3 to avoid deeply nested structures:

```ruby
def walk_structure(obj, prefix, strings, numerics, skipped, depth = 0)
  return if depth > 3

  case obj
  when Hash
    obj.each do |key, value|
      path = prefix.empty? ? key.to_s : '%s.%s' % [prefix, key]
      case value
      when Hash
        walk_structure(value, path, strings, numerics, skipped, depth + 1)
      when Array
        skipped << [path, 'array'] unless value.empty?
      when Numeric
        numerics << path
      when String
        if value.match?(ISO8601_TIMESTAMP_PATTERN)
          skipped << [path, 'timestamp']
        else
          strings << path
        end
      when TrueClass, FalseClass
        strings << path  # booleans can work as label values
      when NilClass
        skipped << [path, 'null']
      end
    end
  end
end
```

**5. `label_name_from_path(path)` private helper:**

Converts a dot-path to a valid Prometheus label name:

```ruby
def label_name_from_path(path)
  # Take the last segment, replace non-alphanumeric with underscore
  name = path.split('.').last.downcase.gsub(/[^a-z0-9]/, '_').gsub(/_+/, '_')
  name = name[1..] while name.start_with?('_')
  name = 'label' if name.empty?
  name
end
```
